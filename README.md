# Лабораторная работа №5

Двумерное умножение матрицы на вектор и метод сопряжённых градиентов.
Отчёт, объяснения, замеры и график: [report.md](report.md).

```bash
python -m pip install -r requirements.txt
mpiexec -n 4 python main.py matvec
mpiexec -n 4 python main.py cg
```

Число процессов: 1, 4, 9, 16, … В `data/sample/` — пример 7×5; `in.dat`: сначала M, затем N.
Для сравнения трёх версий: `python scripts/benchmark.py` (нужен MPI в PATH).
Старые версии ЛР3 находятся в `src/previous/` и используются для сравнения.

Замеры выполнены локально на уменьшенных наборах ЛР4. Доступа к кластеру нет; полноразмерные наборы не измерены.
